# Manual de Design - Atomic Group (Replica)

Este guia documenta os elementos visuais extraídos do site da Atomic Group para uso no template de apresentação comercial.

## 1. Paleta de Cores

### Cores Principais
- **Roxo Atômico:** `#9C51E0` (Destaques, ícones e gradientes)
- **Ciano/Teal:** `#00C2CB` (Acentos secundários)

### Cores de Fundo e Texto
- **Fundo Escuro (Espaço):** `#0B0B2A` a `#000000` (Gradiente vertical)
- **Fundo Claro:** `#FFFFFF` (Seções de conteúdo limpo)
- **Texto Principal:** `#1A1A1A` (Cinza muito escuro/Preto)
- **Destaque Laranja/Amarelo:** `#F9A825` (Usado em gradientes de texto)

### Gradientes
- **Gradiente de Texto (Glow):** `linear-gradient(to right, #9C51E0, #F9A825)`
- **Gradiente de Fundo Hero:** `linear-gradient(180deg, #0B0B2A 0%, #000000 100%)`

## 2. Tipografia

- **Fonte:** `Montserrat`, sans-serif (Google Fonts)
- **Hierarquia:**
    - **H1 (Hero):** 72px / Bold / Cor: `#1A1A1A` (ou Branco em fundos escuros)
    - **H2 (Seções):** 48px / Semi-bold
    - **H3 (Cards):** 32px / Semi-bold
    - **Corpo:** 16px - 18px / Regular

## 3. Elementos de UI

- **Border Radius:**
    - Cards Grandes: `40px`
    - Cards Padrão: `20px`
    - Botões (Pill shape): `50px`
- **Efeitos:**
    - Glassmorphism em seções escuras (Blur + Transparência)
    - Sombras suaves em seções claras
    - Glows neon (roxo/azul) em elementos sobre fundo escuro
